#  Library Management System — Frontend

React-based frontend for the Library Management System.  
This UI connects to the Java Servlets + JDBC backend to provide authentication, book management, and a student dashboard.  

---

##  Features
-  Login & Register pages with validation  
-  Student Books Dashboard (fetch data from backend)  
-  Add / Edit / Delete book flows (with image upload)  
-  Search books by title, author, or ISBN  

---

##  Tech Stack
- **React 18** (with Vite)  
- **Material UI** (MUI v5)  
- **Axios / Fetch API** for HTTP calls  
- **Node.js** (v16+) & npm/yarn  

---


##  Setup Instructions
- Install **Node.js (v16 or newer)**.  
- Clone this repo and open the `frontend/` folder.  
- Install dependencies with `npm install`.  
- Start development server with `npm run dev`.  
- Open app in browser at `http://localhost:5173`.  
- Build production version with `npm run build`.
